## 2. Quá Trình Phân Tích & Brainstorming Phương Án Kiến Trúc

### 2.1. Phân Tích Đánh Đổi (Trade-off Matrix)

| Tiêu Chí Thiết Kế | Phương Án 1: Microservices | Phương Án 2: Modular Monolith (Được Chọn) | Lý Do Lựa Chọn & Rào Chắn Nghiệp Vụ |
| :--- | :--- | :--- | :--- |
| **Độ trễ tương tác (Latency)** | Cao (Nhiều network hops giữa các microservices) | **Cực thấp (In-memory calls giữa Service layers)** | Đáp ứng cam kết SLA phản hồi AI $\le 2.0$ giây cho nhân viên CSKH. |
| **Chi phí vận hành (Ops Overhead)**| Cao (Kubernetes, Service Mesh, Kafka, Docker per service) | **Tối ưu (1 container Next.js + 1 cụm MySQL)** | Giảm 70% chi phí hạ tầng trong giai đoạn tăng trưởng của startup D2C. |
| **Tính đồng nhất dữ liệu** | Phức tạp (Distributed Transactions / Saga) | **Đơn giản & Đáng tin cậy (ACID Transactions của MySQL)** | Đảm bảo tính nhất quán tuyệt đối giữa trạng thái hội thoại và tin nhắn. |
| **Chia sẻ Kiểu Dữ liệu (Type Safety)**| Cần Protobuf / gRPC mã hóa trung gian | **TypeScript Strict đồng bộ 100% End-to-End** | Chia sẻ trực tiếp DTOs và Zod schemas từ Backend tới Frontend UI. |

## 3. Tóm Tắt 4 Hồ Sơ Quyết Định Kiến Trúc (ADR Summary)

1. **ADR-0001: Lựa chọn Kiến trúc Modular Monolith trên Next.js 15**:
   - Sử dụng Next.js App Router (Fullstack Node.js + React 19) phân tách rõ ràng giữa tầng API Route Handlers (`src/app/api/`), Tầng Dịch vụ nghiệp vụ (`src/services/ai/`, `src/services/db/`), và Tầng Giao diện (`src/components/`).
2. **ADR-0002: Cơ chế Xác thực Stateless JWT & Phân quyền RBAC 3 Cấp**:
   - JWT mang payload `{ sub: userId, brandId, role, exp }` với thời hạn 8 giờ (bằng 1 ca trực).
   - Phân cấp 3 vai trò: `AGENT` (CSKH, 1-Click Send, Feedback), `SUPERVISOR` (Giám sát SLA ca trực, Biên tập KB), `ADMIN` (Cấu hình Brand Tone, Phân quyền nhân viên).
3. **ADR-0003: Chiến lược Cô lập Dữ liệu Đa thuê bao (Multi-tenant Isolation) trên MySQL 8.0**:
   - Sử dụng mô hình Shared Database với cột phân biệt `brand_id VARCHAR(36)` bắt buộc trên 100% thực thể nghiệp vụ.
   - Ép buộc lọc tự động thông qua Prisma Client Tenant Extension và bảo vệ bằng Composite Indexes tối ưu.
4. **ADR-0004: Nguyên tắc Điều phối AI Co-pilot & Bắt buộc Định dạng JSON Chuẩn (Structured Outputs)**:
   - Nghiêm cấm tự động gửi tin nhắn (Human-in-the-Loop 100%).
   - Bắt buộc kích hoạt chế độ Structured Outputs JSON Schema trên LLM Provider, kiểm định runtime qua thư viện Zod.
