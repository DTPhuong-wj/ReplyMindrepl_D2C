## 2. Quá Trình Chuyển Đổi Từ PRD Sang Đặc Tả Kỹ Thuật Hành Vi

Hệ thống đã kế thừa trực tiếp tài liệu PRD v1.1.0 và đặc tả hóa các hành vi hệ thống sau:
1. **Auth Simulator & RBAC Route Guard**: Cơ chế chuyển đổi role `Agent` / `Admin` không cần reload trang (< 50ms), tự động ẩn menu Admin khi là Agent và chuyển hướng HTTP 307 kèm Toast cảnh báo nếu Agent cố tình nhập URL trang quản trị.
2. **Máy trạng thái vòng đời hội thoại**: Quy định rõ 4 trạng thái `OPEN` -> `PENDING_CUSTOMER` -> `RESOLVED` -> `CLOSED`.
3. **Luồng thao tác 1-Click Send**: Trình tự 5 bước sao chép bản nháp vào ô soạn thảo, focus con trỏ chuột, cơ chế so sánh chuỗi để tự động phân loại `ACCEPTED_UNMODIFIED` hay `ACCEPTED_WITH_EDITS`.
4. **Kịch bản phục hồi lỗi (Error & Fallback)**: Xử lý gián đoạn mạng hoặc LLM Timeout > 2.5s bằng banner thân thiện, ô soạn thảo không bị vô hiệu hóa; fallback engine nội bộ khi lỗi cú pháp JSON.
5. **Trạng thái UI bắt buộc (Loading / Empty / Error / Success)** cho 4 mô-đun chính: Hộp thư, Khung chat, Thanh bên Co-pilot, Quản lý tri thức.
6. **Xác thực dữ liệu với Zod Schema**: `CreateMessageSchema`, `UpdateBrandToneSchema`, `AIFeedbackSchema`.
